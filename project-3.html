Квиз-лендинг для школы онлайн-курсов

Описание проекта

Образовательная платформа с интерактивной системой подбора профессии.

Задача: помочь новичку не запутаться в обилии направлений и выбрать подходящий курс.

Решение: проектирование вовлекающего квиза (опросника) с моментальным результатом.

Инструменты: Figma, Adaptive Web Design.
