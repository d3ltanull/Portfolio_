Кейс 07 · Приложение

Эстетичный мобильный интерфейс для бьюти-ритейла

Описание проекта

Мобильный интерфейс для покупки уходовой и декоративной косметики.

Задача: создать эстетичное пространство для шопинга с удобным каталогом.

Решение: разработка карточек товаров с детальным описанием состава, интуитивная навигация по категориям и чистый "Beauty" стиль интерфейса.

Инструменты: Figma, Visual Branding, Micro-interactions, UI-UX.
