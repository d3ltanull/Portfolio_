Кейс 05 · Приложение

Социальная экосистема для волонтеров и организаторов мероприятий

Описание проекта

Социальное приложение для волонтеров и организаторов благотворительных мероприятий.

Задача: создать экосистему, где пользователи могут легко находить добрые дела рядом с собой и получать бонусы за участие.

Решение: разработка карты волонтерских событий, системы личных профилей с рейтингом и ленты новостей. Особое внимание уделено интуитивности навигации для разных возрастных групп.

Роль в команде: UX-исследователь, UI-дизайнер (совместно с командой разработчиков).

Инструменты: Mobile UI, User Flow, Prototyping.

Участники: Хавалиц Федор, Федорова Рената, Насонов Максим, Денисенко Андрей.
